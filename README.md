## Featured project

### Project Sentinel — AML Detection & Escrow System

Full-stack anti-money-laundering detection system combining graph neural
networks, smart contract escrow, and zero-knowledge proofs for
privacy-preserving fraud interception.

- Built an AML detection system combining XGBoost and GraphSAGE (PyTorch Geometric) graph neural networks on a 6.3M-transaction dataset, with data-driven threshold policies and leak-proof temporal validation
- Designed and tested a Solidity smart contract for time-locked escrow with automated dispute/refund logic (36 passing tests), plus a Circom/SnarkJS zero-knowledge proof system for privacy-preserving blacklist verification (Groth16, Poseidon hash, sparse Merkle trees)
- Implemented Byzantine-robust federated learning (Multi-Krum) for privacy-preserving multi-institution model training, and a fully CI-tested FastAPI backend with 234+ automated tests
